# Vicohome MQTT Bridge

Vicohome bird-feeder cameras in Home Assistant over MQTT: newest bird, snapshot image, visit
events, today's visit counts, MP4 clips, battery and Wi-Fi.

*Camera in. Wings out.* The bridge between your Vicohome camera and
[un-subscribird](https://github.com/jbuck2005/unsubscribird).

Needs the Mosquitto broker add-on and the MQTT integration. See the Documentation tab for setup.

This project has no connection with Vicohome.
